# Meaningful Icon Pass

## Goal
Improve scanability across every user-facing page with a restrained set of professional line icons while preserving the premium navy and champagne editorial design.

## What will change
- Add a small route-aware icon to shared page headings so About, Portfolio, Process, Blog, FAQ, Contact, and Case Studies each gain a relevant visual cue.
- Add purpose-specific icons to the shared Services, Shopify, Social Media, and Email page sections, including focus areas, capability groups, and working steps.
- Refine homepage service, trust, project, specialist, and final-action cues with consistent commerce-focused icons.
- Extend the same icon treatment to the Sales Proof and individual Blog article pages where shared components do not apply.
- Keep icons minimal, champagne-toned, accessible, and secondary to the content; no generated artwork or decorative clutter.

## Quality checks
- Confirm all content pages load without errors.
- Check desktop and mobile layouts for alignment, overflow, and readable icon sizing.
- Confirm the production build remains healthy.

## Technical details
- Use the existing `lucide-react` library only.
- Centralize repeated icon styling and route-to-icon mapping in shared page components.
- Preserve existing links, copy, forms, metadata, imagery, and contact details.
